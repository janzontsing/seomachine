## Usage Guidelines

### When Writing New Content
1. Check which cluster the topic belongs to
2. Target the appropriate pillar, cluster, or long-tail keyword
3. Include LSI keywords naturally throughout
4. Link to relevant product and application pages
5. Create content that outperforms competitor pages on the same keyword

### When Optimizing Existing Content
1. Verify target keyword alignment with content
2. Check for cannibalization (product page vs. blog post targeting same keyword)
3. Ensure keyword in title, H1, first 100 words, and at least 1-2 H2s
4. Update meta description to include target keyword + CTA
